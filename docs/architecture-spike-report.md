`docs/adr-002-sqlite-driver-measurements.json` contains only the comparable development measurement. The packaged smoke report is authoritative for package build duration, package size, Electron architecture, native module loading, and heartbeat delay.

The local Codex environment currently uses Node 26. Its Forge invocation can terminate without producing `out/`; the smoke writes a `FAILED` report rather than treating that case as success. The CI workflow fixes Node 24 and macOS 14 / arm64 so the target evidence can be reproduced.

## Acceptance transition

Set this section to `GO` and ADR-002 to `ACCEPTED` only after the CI artifact reports `COMPLETE` for both `better-sqlite3` and `node:sqlite`, includes a nonzero package size and package build duration, and each candidate reports heartbeat delay at or below 100ms. Signing and notarization remain a release-distribution Gate; they cannot be verified without the project’s Apple signing credentials.
